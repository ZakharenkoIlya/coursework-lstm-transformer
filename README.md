# coursework-lstm-transformer
# Дослідження ефективності класичних та спеціалізованих нейромережевих архітектур у задачах довгострокового прогнозування часових рядів (LTSF)

Даний репозиторій містить експериментально-програмний комплекс, розроблений у межах преддипломної практики магістра (спеціальність F1 «Прикладна математика», ДНУ ім. Олеся Гончара). 

---

## 📌 Основна мета та завдання дослідження

**Мета практики:** Оцінка ефективності та ресурсоємності класичних рекурентних моделей (LSTM), базових attention-архітектур (Vanilla Transformer) та спеціалізованих LTSF-моделей (DLinear) при збільшенні горизонту прогнозування до **96 кроків**.

### Ключові задачі:
1. **Розширення експериментальної бази:** Залучення нового погодного набору даних (*Weather Dataset*) поруч із базовим бенчмарком *ETTh1*.
2. **Збільшення горизонту прогнозування:** Перехід від короткострокового прогнозу ($H=24$) до довгострокового ($H=96$).
3. **Інтеграція спеціалізованої моделі:** Реалізація та адаптація архітектури **DLinear** (розклад на Trend/Seasonality та лінійне проєктування).
4. **Оцінка часової ефективності:** Замір та аналіз часу навчання (Training Time) та інференсу для кожної з моделей.
5. **Аналіз деградації точності:** Побудова графіків накопичення похибки (MAE) по всьому часовому горизонту від 1 до 96 кроків.
